# Viewi UI

UI library for Viewi

## Install

`composer require viewi/ui`

```php
use Viewi\UI\ViewiUI;

///...
$viewiConfig->use(ViewiUI::class)
```

## Testing

`cd test/js/`

`npm run watch`
